## Part 1：逐款詳細講

### Sideloadly（最推薦入門）

```text
優點：免費、功能齊（改 Bundle ID、export IPA）、Win/Mac 都有
缺點：要手動續簽（7 日）
適合：想完全掌控＋唔介意手動續
```

### AltStore（最省心）

```text
優點：自動續期、手機直接裝 IPA、社群有 App Store
缺點：要電腦 AltServer 在線、同一 Wi-Fi
適合：長期用幾個 app、唔想成日理
```

### TrollStore（最強大，但版本限定）

```text
優點：永久有效、唔使 Apple ID、唔使電腦、手機直接裝
缺點：只支援特定 iOS、Apple 更新可能封
適合：部機支援嘅話，直接首選
```

### Xcode（開發者專用）

```text
優點：正統、簽名 1 年、開發全功能
缺點：要 Mac、要開發者帳號先有用
適合：iOS 開發者
```

## Part 2：點揀？

```text
問自己 3 條問題：
1. 你部機支援 TrollStore 嗎？ → 支援就揀 TrollStore
2. 你長期用定係試玩？ → 長期→AltStore；試玩→Sideloadly
3. 你係開發者？ → 係→Xcode/Developer
```

**最快結論**：

| 情況 | 推薦 |
|------|------|
| 新手、Windows、想簡單 | Sideloadly |
| 長期用幾個開源 app | AltStore |
| 部機支援 | TrollStore |
| 正式開發 | Developer Program + Xcode |

## Part 3：⚠️ 安全紅線（最重要）

側載江湖有好多「唔正路」嘅嘢，以下全部**要避**：

### ❌ 避開：在線簽名網站

```text
「上傳 IPA → 俾你 Apple ID → 幫你簽名」
風險：Apple ID 密碼俾晒人，隨時被盜帳號／被綁架
```

### ❌ 避開：第三方「穩定版」工具

```text
「破解版 Sideloadly」「內測版」——通常挾帶後門
→ 只用官方網站/官方 GitHub
```

### ❌ 避開：收費幫你「永久簽名」服務

```text
佢哋用企業證書（$299），隨時被 Apple 吊銷
→ 你俾咗錢但 app 隨時死，仲可能違反 Apple 條款
```

### ✅ 安全做法

```text
✅ 官方網站／官方 GitHub 下載工具
✅ 只裝開源／免費／你自己嘅 IPA
✅ 開雙重認證
✅ 唔好將 Apple ID 密碼交俾任何第三方
✅ 定期檢查安裝咗咩 app
```

## Part 4：簽名方式總結對比

| 簽名方式 | 費用 | 有效期 | 上限 | 風險 |
|----------|------|--------|------|------|
| 免費 Apple ID | $0 | 7 日 | 3 app | 低 |
| 個人開發者 | $99/年 | 1 年 | 100 設備 | 低 |
| 企業開發者 | $299/年 | 1 年 | 內部分發 | 中（易被誤用） |
| TrollStore | $0 | 永久 | 無限 | 中（漏洞可能被封） |

## 總結

- 新手最簡單：**Sideloadly**（免費、功能齊）
- 長期用：**AltStore**（自動續期）
- 神器：**TrollStore**（部機支援就首選）
- 正統：**Developer Program**
- **安全永遠第一**：只用官方工具、唔交密碼、只裝合法 IPA
