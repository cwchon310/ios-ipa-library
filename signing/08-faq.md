## Q1：側載係咪犯法？

**答**：側載本身唔犯法。犯法嘅係裝**盜版**（付費 app 偷雞版）。本收納庫只推薦開源／免費／你有權限嘅 app。詳細見 README 聲明。

## Q2：免費 Apple ID 簽名真係免費？有冇陷阱？

**答**：真係免費，冇隱藏收費。唯一「陷阱」係 **7 日要續簽一次**，同埋最多同時 **3 個 app**。想自動續用 AltStore（04 篇）。

## Q3：簽名之後 app 幾時會過期？

**答**：睇簽名方式：
- 免費 Apple ID → 7 日
- 開發者帳號 → 1 年
- TrollStore → 永久

## Q4：過期之後點算？資料會唔會冇？

**答**：重新簽名安裝就開得返。**app 嘅資料（如設定）通常保留**，因為佢喺沙盒入面。但建議過期前續簽（AltStore 會自動做）。

## Q5：點解裝完開唔到，話「無法驗證 App」？

**答**：兩個原因：
1. 未信任憑證 → `設定 → 一般 → VPN 與裝置管理 → 信任`
2. 已過期 → 重新簽名

## Q6：可以唔用電腦直接裝 IPA 嗎？

**答**：
- **TrollStore**：可以，手機直接裝（部機支援先得）
- **AltStore**：可以喺手機裝，但要先有 AltStore（第一次要電腦）
- **其他**：一般要電腦

## Q7：我部機支援 TrollStore 嗎？

**答**：睇 iOS 版本同設備型號。**一定去官方 Git 睇**：`github.com/opa334/TrollStore`。唔支援就唔好亂裝。

## Q8：簽名嗰陣要我 Apple ID 密碼，安全嗎？

**答**：用**官方工具**（Sideloadly/AltStore）係安全嘅，佢哋用 Apple 官方 API 簽名。但**唔好**將密碼交俾「在線簽名網站」或嚟路不明嘅工具。

## Q9：點解裝唔到，話「已達限制」？

**答**：免費 Apple ID 同時最多 3 個 app。刪走一個唔用嘅 app，或者用 Sideloadly 改 Bundle ID。

## Q10：側載嘅 app 會收到更新嗎？

**答**：**唔會自動更新**（除非係 AltStore 社群 Store）。要更新就自己去下載新版 IPA 重新簽名安裝。

## Q11：升級 iOS 會點？

**答**：
- 免費簽名嘅 app：照用，但要重新信任（可能）
- TrollStore：**升級 iOS 前一定要確認 TrollStore 支援新版**，否則 TrollStore 同啲 app 會失效
- 開發者簽名：照用

## Q12：可以側載 App Store 有嘅 app 嗎？

**答**：**技術上可以，但唔建議**——通常涉及版權問題。本收納庫只推薦開源／免費替代品。

## Q13：TrollStore 同越獄有咩分別？

**答**：TrollStore 只係「免簽名安裝器」，唔會改系統，唔可以裝 tweak。越獄係全面改系統（要 Cydia/Sileo 等）。TrollStore 比越獄安全同低調好多。

## Q14：我要開發自己嘅 app，點開始？

**答**：直接裝 Xcode（免費），用免費 Apple ID 都可以開發同裝自己部機（7 日）。想長期／上架 App Store，先申請 Developer Program（06 篇）。

## Q15：側載有冇可能整壞部機？

**答**：正常側載（Sideloadly/AltStore/TrollStore）**唔會整壞部機**，因為唔改系統。風險主要嚟自：裝嚟路不明嘅工具或 IPA。跟足本收納庫指引就安全。
