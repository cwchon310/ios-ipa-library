# 01 · 簽名係咩？IPA／簽名／憑證基礎概念

> 裝任何唔喺 App Store 嘅 app 之前，你先要明白：咩係 IPA、咩係簽名、點解要簽名。

## 呢篇學到

1. IPA 檔係咩
2. 點解 iPhone 一定要「簽名」先裝到
3. Apple ID 簽名／開發者憑證嘅分別
4. 唔同簽名方式嘅有效期限
5. 簽名原理（簡單版）

---

## Part 0：IPA 檔係咩？

**IPA** = iOS App Archive，即係「iOS 應用壓縮包」。佢本質上係一個 **ZIP 檔案**，入面裝住：

```
AppName.ipa            （ZIP 格式）
├── Payload/
│   └── AppName.app/   （應用主體，係一個資料夾）
│       ├── AppName    （已編譯嘅執行檔，Mach-O）
│       ├── Info.plist （應用資訊：Bundle ID、版本等）
│       ├── Assets/    （圖片、資源）
│       └── Frameworks/（依賴框架）
```

你可以直接將 `.ipa` 改名做 `.zip` 解壓睇入面，原理就係咁簡單。

**IPA 邊度嚟？**
- App Store：官方下載（但你攞唔到原始 IPA）
- 開發者自行編譯（Xcode 輸出 `.ipa`）
- 開源項目提供（例如 GitHub Releases 有現成 IPA）

---

## Part 1：點解一定要簽名？

iOS 係「封閉生態」：**所有 app 都要有有效嘅「數碼簽名」先可以安裝同運行**。呢個係 Apple 嘅安全機制（代碼簽名 + 憑證驗證）。

冇簽名 = 系統直接拒絕安裝。

「簽名」就好似 app 嘅「電子身份證」：
- 證明「呢個 app 係邊個整嘅」
- 證明「冇被篡改過」（完整性）
- 決定「佢有咩權限」

---

## Part 2：簽名嘅憑證（Certificate）邊度嚟？

簽名需要一張「憑證」。來源有幾種：

| 憑證來源 | 費用 | 有效期 | 安裝限制 |
|----------|------|--------|----------|
| **免費 Apple ID** | $0 | 7 日 | 最多 3 個 app 同時 |
| **個人開發者帳號** | $99/年 | 1 年 | 100 部設備 |
| **企業開發者帳號** | $299/年 | 1 年 | 唔使 UDID（內部分發） |
| **TrollStore** | $0 | 永久 | 支援設備先得（唔使簽名） |

**最常見起步：免費 Apple ID 簽名**（7 日續一次）。想長用→AltStore 自動續期；想專業→開發者帳號。

---

## Part 3：簽名入面發生咩事（簡單版）

```
你有一個 IPA
      │
      ▼
用 Apple ID（免費）／開發者憑證（付費）做簽名
      │
      ▼
簽名後嘅 IPA（已注入你嘅憑證）
      │
      ▼
透過 Sideloadly / AltStore / Xcode 裝上 iPhone
      │
      ▼
iPhone 驗證簽名 → 有效 → 安裝成功
```

**關鍵位**：免費 Apple ID 簽名，你嘅憑證有效期係 **7 日**。7 日後要重新簽名一次（或用 AltStore 自動續）。

---

## Part 4：簽名前要準備咩？

| 項目 | 說明 |
|------|------|
| 一部 iPhone/iPad | 系統版本唔同，支援嘅方法唔同 |
| 一個 Apple ID | 免費（建議開啟雙重認證） |
| 一部電腦（Windows/Mac） | 用嚟跑簽名工具 |
| 簽名工具 | Sideloadly / AltStore 等 |
| 一個 IPA | 開源／免費／你自己嘅 |

> ⚠️ **安全提示**：簽名工具要用官方／開源知名度高嘅（Sideloadly、AltStore）。唔好用嚟路不明嘅「簽名平台」，佢哋可能要你 Apple ID 密碼——被盜風險極高。

---

## Part 5：邊種簽名方式啱你？

| 你嘅情況 | 推薦方式 |
|----------|----------|
| 新手／試玩 | 免費 Apple ID（02 篇） |
| Windows 用戶 | Sideloadly（03 篇） |
| 想自動續期唔使理 | AltStore（04 篇） |
| 部機支援 TrollStore | TrollStore（05 篇） |
| 大量安裝／公司用 | 開發者帳號（06 篇） |

## 總結

| 概念 | 一句講 |
|------|--------|
| IPA | app 嘅壓縮包（ZIP） |
| 簽名 | app 嘅電子身份證 |
| 憑證 | 身份證邊度嚟（Apple ID／開發者） |
| 免費 Apple ID | 7 日有效期 |
| 開發者帳號 | 1 年有效，$99 |
