## 開源遊戲推薦

| 遊戲 | 類型 | 來源 | 備註 |
|------|------|------|------|
| **2048** | 益智 | GitHub 搜尋「2048 iOS」 | 有開源版本 |

> ⚠️ 開源遊戲嘅 IPA 未必每次有現成，要睇 GitHub Releases 或自行用 Xcode Build。

## 模擬器（最熱門）

| 模擬器 | 模擬平台 | 來源 | 備註 |
|--------|----------|------|------|
| **RetroArch** | 多平台（NES/SNES/PS1/GBA 等） | 官方網站 retroarch.com | 免費，強烈推薦 |
| **Delta** | NES/GBA/DS | GitHub（開源） | 後生開發者作品 |
| **PPSSPP** | PSP | 官方網站 ppsspp.org | 免費開源 |
| **DolphiniOS** | GameCube/Wii | GitHub | 測試階段 |

> 📌 **ROM 版權提醒**：模擬器本身合法開源，但你要玩嘅「遊戲 ROM」必須係你有權限嘅（例如自己嘅正版遊戲 dump）。本收納庫唔提供任何 ROM。

### RetroArch 安裝重點

```text
1. 去官方網站下載對應 iOS 版本 IPA
2. 用 Sideloadly（03 篇）或 AltStore 簽名安裝
3. 第一次開要「信任憑證」
4. 入面再下載「核心（Core）」先玩到
```

## 安全提醒

- ✅ 只裝官方 GitHub / 官方網站嘅 IPA
- ❌ 唔好裝「打包好嘅 ROM + 模擬器」合集（多數含版權問題或病毒）
- ❌ 唔好裝付費遊戲嘅盜版

## 總結

- 模擬器係開源遊戲最大類別，RetroArch 首選
- ROM 要自己有權限先得
- 全部經 Sideloadly/AltStore/TrollStore 安裝
