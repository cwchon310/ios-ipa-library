## 重點推介

### Kiwix（離線維基）

```text
下載一份維基百科離線包，冇網絡都睇到
來源：官方網站 kiwix.org 有 iOS 版
安裝：App Store 有，或 GitHub 側載
超正：離線學習、旅行冇網時救命
```

### FBReader（電子書）

```text
支援 EPUB / FB2 / PDF 等格式
來源：GitHub「geometer/FBReader」有 iOS 源碼
安裝：App Store 免費版／側載
```

### BookPlayer（有聲書）

```text
開源有聲書播放器，支援 M4B/MP3
來源：GitHub「TortugaPower/BookPlayer」
安裝：App Store 有／GitHub 側載
```
