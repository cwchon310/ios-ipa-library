## 重點推介

### VLC（首選）

```text
全球最強開源播放器：乜格式都播、字幕、串流、網絡播放
來源：App Store 免費 / GitHub「videolan/vlc-ios」
安裝：App Store 直接裝（唔使側載）
```

### mpv（開源側載）

```text
技術向開源播放器，支援強勁
來源：GitHub 搜尋「mpv iOS build」
安裝：下載 IPA → 側載（03/04 篇）
適合：進階用戶
```

### Playback（開源）

```text
GitHub 開源播放器，支援各種格式
來源：GitHub「mibrahimdev/Playback」
安裝：GitHub Release 有 IPA
```

## 播放器點揀？

| 你嘅需要 | 推薦 |
|----------|------|
| 乜都要播、穩陣 | VLC（App Store） |
| 追求開源可控 | mpv / Playback（側載） |
| 網絡串流 | VLC（支援串流網址） |
| 字幕支援 | VLC 最齊 |

---

## 影音檔案來源（合法）

| 來源 | 說明 |
|------|------|
| 自己嘅正版影片／音樂 | 由電腦傳過去 |
| 公有領域影片 | Archive.org 等 |
| 直播串流網址 | 官方公開串流 |

> ⚠️ 唔好裝「下載 YouTube」類工具去偷片，亦唔好側載「破解版影音 app」。

---

## 安全提醒

- ✅ VLC 係安全正路，App Store 直接裝
- ⚠️ mpv/Playback 側載要用官方 GitHub 來源
- ❌ 唔好用「免費看片」app（多數含廣告／病毒）

---

## 總結

- **VLC 已經解決 90% 需求**，App Store 免費
- 想更開源可控先考慮 mpv / Playback 側載
- 影音檔案要自己合法擁有先得
