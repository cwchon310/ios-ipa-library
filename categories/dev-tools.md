## 重點推介

### iSH（最推薦）

```text
「將一個 Linux 環境放喺 iPhone」——可以直接跑 apk/ssh/python 等
來源：GitHub「ish-app/ish」
安裝：App Store 有免費版，或 GitHub 下載 IPA 側載
用法：裝完入面有 apk（Alpine 套件管理），想裝咩都得
```

### a-Shell

```text
輕量本機終端：vimgit、ssh、python 都得
來源：App Store 免費 / GitHub「holly-app/holly」
```

### Working Copy（Git）

```text
手機上管理 Git repo、commit、push
來源：App Store（有免費功能）
```

## 點側載開發工具？

開發工具通常有兩個來源：

| 來源 | 做法 |
|------|------|
| **App Store 免費版** | 直接裝（最簡單，唔使側載） |
| **GitHub 開源 IPA** | 下載 → Sideloadly/AltStore 簽名（03/04 篇） |

> 💡 好多開發工具 App Store 有免費版，**先睇 App Store**，冇先諗側載。

---

## 安全提醒

- ✅ 只裝官方 GitHub 嘅開源工具
- ❌ 唔好用嚟路不明嘅「破解版 Pro 工具」
- ⚠️ SSH 工具涉及密鑰，一定要官方來源

---

## 總結

- iSH 係最正嘅「手機 Linux 環境」
- 多數開發工具 App Store 有免費版，先試
- 真係要側載先睇 GitHub 開源項目
