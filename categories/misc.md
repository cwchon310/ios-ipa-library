## 重點推介

### Bitwarden（密碼管理首選）

```text
開源密碼管理器，跨平台，可以自己架 server
來源：官方網站 bitwarden.com / App Store / GitHub
安裝：App Store 直接裝
超正：密碼加密儲存、自動填表
```

### KeePass（進階開源）

```text
老牌開源密碼庫，KeePass 檔案格式
來源：GitHub 有 iOS 客戶端（KeePassTouch 等）
安裝：App Store 有免費版
```
