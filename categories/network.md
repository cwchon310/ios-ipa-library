## 重點推介

### Signal（最安全通訊）

```text
開源、端到端加密，全球公認最安全通訊 app
來源：官方網站 signal.org / App Store
安裝：App Store 直接裝，唔使側載
```

### Element（Matrix）

```text
開源去中心化通訊協議 Matrix 嘅官方 app
適合：想自己架 server 嘅進階用戶
來源：GitHub「element-hq/element-ios」
```

### 開源瀏覽器

```text
Firefox / Brave / DuckDuckGo：全部 App Store 有、開源
唔使側載，直接用
```

---

## VPN／代理注意事項

```text
⚠️ 網絡通訊工具（尤其 VPN）涉及安全，只可以用官方來源
✅ Tailscale / OpenVPN / WireGuard 都係正路
❌ 唔好用「免費 VPN」嚟路不明 app（多數竊取資料）
```

---

## 安全提醒

- ✅ 通訊 app 首選官方 App Store（Signal/Telegram 都係）
- ✅ 開源項目（Element）可以側載但優先官方
- ⚠️ VPN 一定要官方 app
- ❌ 唔好裝「改機版」通訊 app（通常偷資料）

---

## 總結

- 通訊／瀏覽器：**App Store 官方版已經係最好**，多數開源
- 要側載嘅：Element 等自架 server 嘅進階用戶
- 網絡工具同 VPN 一定要官方來源
